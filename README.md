# Zann-Gaming-Tools

<p align="center">
  <b>A lightweight, fast, and feature-rich utility suite designed for gamers.</b>
</p>

---

## Overview

**Zann Gaming Tools** is a standalone Windows desktop application built with C++ / Win32 and WebView2 technology. It offers an easy-to-use GUI for essential gaming utilities and enhancements.

---

## How to Install & Run

You **do not** need to build the project from source to run the app. Pre-compiled standalone installers are available on GitHub Releases:

1. Go to the [**Releases**](https://github.com/Fauzanhandriansyah/Zann-Gaming-Tools/releases) page.
2. Download the latest `ZannGamingTools-win-Setup.exe`.
3. Run the installer wizard and launch the application!

---

## Features

-  **High Performance:** Minimal resource usage with native Win32/WebView2 integration.
-  **Clean UI:** Simple, modern, and user-friendly interface.
-  **All-in-One Installer:** Built-in dependencies and auto-configurations via Inno Setup.

---

## Requirements

- **OS:** Windows 10 / Windows 11 (64-bit)
- **Runtime:** Microsoft Edge WebView2 Runtime (Included/Auto-detected)
